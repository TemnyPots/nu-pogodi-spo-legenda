# VK Mini Apps — подключение

Существующий сайт: https://nu-pogodi-spo-legenda.kislinya.chatgpt.site/

1. Создать мини-приложение в кабинете https://dev.vk.ru/ru/admin/create-app .
2. Название: «Ну, кирпичи! — СПО Легенда». Тип: VK Mini Apps.
3. Указать HTTPS-адрес выше для поддерживаемых платформ: веб, мобильный веб, Android и iOS. Если есть отдельные поля разработки и рабочего адреса — заполнить соответствующие поля этим адресом.
4. Сохранить настройки. Открыть приложение из кабинета: сайт должен получить параметры vk_app_id и vk_platform. Не вписывать их вручную в рабочий адрес.
5. Проверить запуск, имя/аватарку, начало игры, сенсорные кнопки, паузу при сворачивании, окончание и запись результата, таблицу, действия «Поделиться» и «В избранное» (если поддерживаются клиентом).
6. Перед подачей в каталог заполнить запрошенные VK сведения о владельце/контактах и правах на графику. Правила модерации и правомерность использования исходных персонажей подтверждает владелец. Публикация сайта не равна одобрению каталога VK.

Описание: «Лови кирпичи вместе с волком из СПО Легенда! Четыре позиции корзины, красные и синие кирпичи, растущая скорость и общая таблица рекордов. Управление касаниями или клавиатурой».

Об игре и используемых данных: https://nu-pogodi-spo-legenda.kislinya.chatgpt.site/about

Иконка: outputs/vk-mini-app/icon-256.png (портрет волка).

## Что реализовано
- Официальный @vkontakte/vk-bridge 3.0.2, VKWebAppInit без ожидания заставки.
- Имя и аватарка VK, редактируемый ник, общая существующая таблица с сайтом.
- Безопасные отступы, сенсорное управление и адаптация к высоте экрана.
- Остановка звука/пауза при VKWebAppViewHide, возврат без автоматического возобновления партии.
- Поделиться и добавить в избранное только после нажатия игроком и при поддержке клиента.
- Ограниченное ожидание ответов Bridge: отсутствие VK не блокирует обычную игру.

## Модель данных и границы
Параметры запуска используются только для выбора интерфейса. Проверка подписи sign и серверная привязка рекордов к vk_user_id не реализованы: общая таблица, как и прежде, группируется по выбранному никнейму. Имя из VK не является доказательством личности на сервере. Секретный ключ приложения для текущей интеграции не нужен и не должен находиться в клиентском коде.

ID и ссылка приложения пока не предоставлены. Создание, настройка кабинета и проверка в настоящем клиенте VK требуют владельца: автоматизированный браузер блокирует vk.ru. После сохранения настроек отправьте точную ссылку приложения, а при ошибке — снимок экрана.
